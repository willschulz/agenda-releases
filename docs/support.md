# Agenda support

**Report a problem or request a feature** at
[github.com/willschulz/agenda-releases/issues](https://github.com/willschulz/agenda-releases/issues).
In the Mac app, **Settings → Data and support → Report a Problem…** opens the
form with Agenda's version filled in. Issues are public, so please don't
include private project names or notes.

**Backups.** Agenda keeps automatic snapshots of your board.
**Settings → Data and support → Reveal Backups in Finder** shows them.

**iPhone and iPad.** The companion app shows the board from Agenda for Mac.
Install Agenda on your Mac, sign in to iCloud there with the same Apple ID
as your iPhone, and open it once while online. If your board doesn't appear
on the iPhone, open Agenda on the Mac and wait a minute.

**Updates.** Agenda for Mac updates itself. To check now, use
**Settings → Data and support → Check for Updates…**, or
download the latest version from the [download page](./).
