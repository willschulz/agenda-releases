# Agenda

A calm, local-first project tracker for macOS. Projects and todos live on one
board, arranged in rows by priority. It works offline, keeps your data on
your Mac, and is built to be driven by coding agents such as Claude Code and
Cursor.

## Download

**[Download Agenda for Mac](https://github.com/willschulz/agenda-releases/releases/latest)**:
open the `.dmg` and drag Agenda to Applications.

- Requires a Mac with Apple silicon and macOS 13 or later.
- Signed and notarized by Apple. Agenda updates itself when a new version is
  released.
- Free and open source (GPL-3.0). Source code:
  [github.com/willschulz/agenda](https://github.com/willschulz/agenda).

**iPhone and iPad:** a companion app that syncs with Agenda for Mac through
your private iCloud is in testing. A TestFlight link will be posted here.
